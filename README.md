# Application de suivi des immersions
Cette application web (HTML/CSS/JS) entièrement Vibecodé par ChatGPT (Codex) permet d'assurer le suivi des immersions en établissement. Cette application locale n'envoie aucune donnée sur un serveur, elle tourne entièrement en locale sur votre poste.

# Fonctionnalités :
* L'application vous permet de consigner une nouvelle immersion, en saisissant le nom, prénom, l'établissement d'orgine, la classe d'origine, l'établissement d'accueil, la classe d'accueil et les dates d'immersions.
* L'application vous permet de suivre l'état de votre immersion entre différents statuts
* L'application vous permet de suivre l'état des demandes de réaffectation pour des élèves ayant effectués une demande d'immersion par le passé.
* L'application propose un tableau de bord statistiques vous permettant de piloter votre politique d'immersion.
